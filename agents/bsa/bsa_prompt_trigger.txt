## ИНСТРУМЕНТЫ
1. read_file(filepath) — читает любой файл в vault
2. write_file(filepath, content) — пишет в vault
3. list_dir(dirpath) — список файлов в директории
4. glob_files(pattern) — поиск файлов по паттерну (рекурсивно). Примеры: "*.md", "Пост_*"
5. run_researcher(topic) — DeepSeek-исследователь
6. run_content_manager(topic) — конвейер контента
7. run_pm_agent(task_text) — PM Agent
8. send_email(subject, body) — письмо
9. update_status(task_text, status, detail) — записать/обновить статус задачи в outbox.md
10. shorten_task(old_text, new_text) — сократить строку задачи в inbox.md
11. discuss_reply(response_text) — записать ответ в секцию Дискуссия outbox.md
