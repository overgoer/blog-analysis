# Backend Tip: HTTP Status Codes: 4xx & 5xx
📅 2026-05-07

## Зачем это нужно
Distinguish client vs server errors — tells you who to blame

## Совет
400 Bad Request (client sent bad data), 401 Unauthorized (no auth), 403 Forbidden (no permission), 404 Not Found, 409 Conflict (duplicate/state conflict), 422 Unprocessable (validation failed), 429 Too Many Requests, 500 Internal Server Error (backend bug), 502 Bad Gateway, 503 Service Unavailable.
