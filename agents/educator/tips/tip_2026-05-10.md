# Backend Tip: SQL: INNER JOIN vs LEFT JOIN
📅 2026-05-10

## Зачем это нужно
Wrong join type = missing or duplicate data in test results

## Совет
INNER JOIN returns only matching rows in both tables. LEFT JOIN returns ALL left-table rows + matches from right (NULLs where no match). Always check which you need in test assertions.
