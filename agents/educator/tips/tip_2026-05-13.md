# Backend Tip: SQL: GROUP BY & Aggregation Gotchas
📅 2026-05-13

## Зачем это нужно
Most common SQL mistakes in test validation come from misunderstanding GROUP BY

## Совет
Every column in SELECT must be either in GROUP BY or wrapped in an aggregate (COUNT, SUM, MAX, etc.). PostgreSQL is strict; MySQL is lenient (silent wrong data!).
