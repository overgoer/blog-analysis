# Backend Tip: SQL: EXPLAIN Query Plan
📅 2026-05-12

## Зачем это нужно
See how the DB actually executes your query, spot missing indexes

## Совет
Run EXPLAIN ANALYZE SELECT ... (PostgreSQL). Look for 'Seq Scan' on large tables — that means a full table scan. Add indexes for WHERE/ JOIN columns.
