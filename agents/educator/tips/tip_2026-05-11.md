# Backend Tip: Logging & Correlation IDs
📅 2026-05-11

## Зачем это нужно
Debug production issues by tracing a request across multiple services

## Совет
Correlation ID (X-Request-ID) is passed through all services in a request chain. Test: send request with your own X-Request-ID → find it in all service logs. If missing, bug report filed.
