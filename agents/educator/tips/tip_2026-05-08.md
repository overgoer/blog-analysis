# Backend Tip: Content Negotiation (Accept / Content-Type)
📅 2026-05-08

## Зачем это нужно
API can return JSON, XML, or something else — test that right format comes back

## Совет
Client sends Accept: application/json → server should return Content-Type: application/json. If Accept is missing, what does the server default to? Test with different Accept values including */*.
