## Sessions vs Tokens

**Зачем:** Two fundamentally different auth models — each affects testing differently

**Совет:** Session: server stores session, client sends cookie. Token (JWT): everything in token, server is stateless. Sessions are easier to revoke (delete server-side), tokens need a blocklist. Test: logout, token refresh, session expiry.

Теги: #auth #api #design

## HATEOAS & REST Discovery

**Зачем:** Some APIs return links for next actions — test the full flow

**Совет:** Response includes 'links' object with 'self', 'next', 'related' URLs. Test: follow the links programmatically instead of hardcoding URLs. Break a link → check that error is handled gracefully.

Теги: #api #design #advanced

----

## Message Queues (RabbitMQ, Kafka)

**Зачем:** Async processing — user gets response immediately, work happens later

**Совет:** Messages are published to queues/exchanges, consumed asynchronously. Test: publish a message, verify consumer processes it (may take seconds). Check: message persistence, dead letter queues (failed messages), delivery guarantees (at-most-once, at-least-once).

Теги: #queue #api #advanced

----

## SQL: Transactions & Rollback

**Зачем:** Understand how atomic operations work — critical for testing payment/order flows

**Совет:** BEGIN; ... COMMIT; makes multiple operations atomic. ROLLBACK; undoes all changes. Test that partial failures don't leave half-applied data (e.g., payment captured but order not created).

Теги: #sql #database #testing

----

## JWT (JSON Web Tokens)

**Зачем:** Most common auth mechanism — understand what's in the token

**Совет:** JWT has 3 parts: header.payload.signature (base64url-encoded). Decode at jwt.io. Check: token expiration (exp claim), algorithm confusion attacks (change alg to 'none'), signature validation failures.

Теги: #auth #security #api

----

## Postman: Tests Tab & Assertions

**Зачем:** Validate API responses automatically without manual checking

**Совет:** Use pm.test() and pm.expect() in the Tests tab. Check status codes, response time (< 200ms), and JSON body structure.

Теги: #postman #api #testing
