# Контент-календарь QA-канала

## Стратегия публикации

### Частота
- **Пн-Чт**: 1 пост в день
- **Пт**: 1 пост (легкий / мем / дайджест)
- **Сб-Вс**: отдых

### Время (гипотеза для A/B-теста)
| День | Время (МСК) | Тип контента |
|------|-------------|--------------|

| Пт | 16:00 | Мем / легкое |

## Форматы постов

### A: Байка / кейс — история с выводом
```
**🔥 [ЗАГОЛОВОК]**

[Ситуация — 2-3 предложения]
[Что пошло не так]
[Как нашли — случайно / через отчёт / клиент]
[Корень — технически, простыми словами]
[Фикс / урок]
[Вопрос к аудитории]

#тестирование #баги #кейс
```

### B: Чек-лист / методика
```
**📋 [ТЕМА]: [ИНТРИГА]**

[Вступление — почему это важно]

✅ Пункт 1
✅ Пункт 2
✅ Пункт 3

🔥 Бонус: неочевидный пункт

#тестирование #чеклист #методика
```

### C: Провокация / опрос
```
**🤔 [ВОПРОС]**

[Контекст — 1-2 предложения]

👇 А как у вас?
[Вариант 1]
[Вариант 2]
[Вариант 3]
```

### D: Разбор / гайд
```
**📖 [ТЕМА]: [ПРОБЛЕМА → РЕШЕНИЕ]**

[Проблема]
[Корень]
[Решение — пошагово]
[Чек-лист внедрения]

#тестирование #гайд #разбор
```
